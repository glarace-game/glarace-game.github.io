# ПЕРЕДАЧА — Glarace (продолжить в новом окне)

**Дата:** 13 августа 2026

## Что за проект
Glarace — 3D дрифт-игра в браузере. Делаю вместе с сыном **Львом Лари**.
Стиль-референс — **CarX Drift Racing**. Концепт: гонки по разным городам, первая трасса — **улицы Петербурга**.

  - `ТЗ-Петербург-реализм.md` (и PDF) — план следующего этапа

## Что уже готово (версия 2)
- 3D, камера за машиной; физика дрифта (руль исправлен, занос сделан управляемым).
- **Гараж:** выбор модели (3), цвета (8), наклеек (полосы/номер/молния), тюнинг (мощность/сцепление/управляемость). Сохраняется в браузере.
- **Трасса-кольцо** с красно-белыми поребриками и разметкой; пейзаж — небо, горы, деревья.
- Движок Three.js **лежит локально** (важно: CDN jsDelivr в РФ часто блокируется, а старый Safari не грузил его через сеть — поэтому офлайн).

## Что решаем дальше
Приблизить картинку к CarX (реалистично, но не буквально AAA — это невозможно в браузере) и построить **трассу по Петербургу**. Полный план по шагам — в файле `ТЗ-Петербург-реализм.md`.

**Открытая развилка (выбрать):** машины делаем
- **Вариант А (рекомендуется):** процедурно из кода — офлайн, 0 веса, Лев правит числа. Стилизованно.
- **Вариант Б:** реальные 3D-модели (glTF) — детальнее, но тяжелее, лицензии, и сын уже не правит числа.

## Заметки для исполнителя (Claude в новом окне)
- Все числа физики машины — в блоке `TUNE` вверху `index.html`.
- **Проверка/превью:** harness-браузер не открывает файлы с Desktop (песочница) и ставит анимацию (rAF) на паузу в фоне. Проверять статикой: поднять из Bash `python3 -m http.server 5193 --directory "/Users/Admin/Desktop/алаб/гонки"`, открывать `http://localhost:5193/`; вместо `preview_click` использовать `element.click()` через eval; скриншот показывает один кадр.
- **Деплой:** коммит + push в репозиторий → GitHub Pages обновляется за 1–3 минуты.
- Three.js версии r160. Любые аддоны (пост-обработка) класть **физически в `vendor/`** и импортировать локально — без CDN.
