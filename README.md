# Glarace

3D дрифт-игра. Вид из-за машины, реалистичная физика заноса. Референс — CarsXDriftRacing.

**Авторы:** Лев Лари и Claude.

## Играть
Открой ссылку: **https://glarace-game.github.io/**
(с телефона или компьютера, ничего устанавливать не надо)

## Управление
- **↑** — газ
- **↓** — тормоз / задний ход
- **← →** — руль
- **Пробел** — ручник (срывает машину в занос)
- **R** — начать заново

Смысл: входи в поворот на скорости, зажми ручник и подруливай — держи занос, чтобы копить очки. Сбивай конусы.

## Как запустить у себя на компьютере
Просто открой файл `index.html` двойным кликом в браузере (нужен интернет — 3D-движок подгружается из сети).

## Технологии
- Один файл `index.html`
- Движок [Three.js](https://threejs.org/) (загружается из CDN)
- Вся физика собрана в блоке `TUNE` вверху скрипта — числа удобно менять и смотреть результат

## Файлы
- `index.html` — сама игра
- `ПРОЕКТ-гонки.md` — описание проекта и журнал работы
